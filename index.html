Step 1 — Set up Google Sheets backend
One-time setup (5 minutes):
1. Go to sheets.google.com → create a new sheet named "PharmaCom Submissions"
2. Click Extensions → Apps Script
3. Delete the default code, paste the code from the apps_script_backend.gs file
4. Click Deploy → New Deployment → Web App
5. Set "Execute as: Me" and "Who has access: Anyone"
6. Click Deploy → copy the Web App URL below
Free hosting for mr_visit_form.html: Upload it to GitHub Pages (free) or any static hosting. The MR accesses it via their QR code. It only needs internet access to submit — no server needed on your side.
Step 2 — Assign drugs to MRs in Drug Master

Make sure each drug in the Drug Master has an MR assigned. The MR form will show only their company's drugs as options when they fill in the visit.
